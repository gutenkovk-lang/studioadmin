# Студия — приложение администратора фотостудии (iOS)

Нативное приложение на SwiftUI. Нужны Mac с Xcode 16 или новее и iPhone с iOS 17 или новее.

## Как запустить

1. Откройте `StudioAdmin.xcodeproj` в Xcode.
2. Слева выберите проект → цель **StudioAdmin** → вкладка **Signing & Capabilities** → в поле **Team** выберите свой Apple ID
   (бесплатного достаточно). При необходимости замените Bundle Identifier `com.example.StudioAdmin` на свой.
3. Подключите iPhone, выберите его вверху окна и нажмите ▶.
4. При первом запуске разрешите уведомления — без них сигнал не придёт, когда приложение свёрнуто.

Вибрация и звук уведомлений работают только на настоящем iPhone, не в симуляторе.
С бесплатным Apple ID приложение на телефоне нужно переустанавливать из Xcode раз в 7 дней;
с платным аккаунтом разработчика — раз в год, либо можно выложить в TestFlight / App Store.

## Что где

| Файл | Что внутри |
|---|---|
| `Models.swift` | Клиент, зал, аренда, настройки |
| `Store.swift` | Все данные и действия, сохранение в файл на устройстве |
| `AlarmManager.swift` | Уведомления, мелодия, вибрация |
| `HallsView.swift` | Главный экран с залами и таймерами |
| `RentalSheets.swift` | Новая аренда, выбор клиента, текущая аренда |
| `ClientsView.swift` | База клиентов |
| `EarningsView.swift` | Заработок и график |
| `SettingsView.swift` | Настройки и залы |
| `chime.wav`, `harp.wav`, `signal.wav` | Мелодии сигнала (можно заменить своими, до 30 секунд) |

Данные хранятся только на телефоне, в файле `studio-data.json` в папке приложения.
